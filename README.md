## 📖 项目简介

**灵动云（LingDongYun）官方品牌官网**，专为跨国网络加速、出海远程办公、4K/8K 超清流媒体播放及生成式 AI（ChatGPT / Claude / Midjourney）生产力交互提供高品质、低延迟、高可用的专线连接服务。

网站基于现代化的 **Astro 5 + TypeScript + Tailwind CSS 4** 架构构建，具备全量静态 HTML 生成（SSG）、毫秒级首屏加载性能与顶级的 Google / Bing SEO / GEO 搜索优化标准。

### 1. 🚀 BGP 线路与智能节点架构
采用 **BGP 多线接入与骨干网络互通架构**，涵盖国内主流运营商互联入口。系统动态探测跨境链路状态与网络拥塞情况，具备多路由冗余自动切换能力，确保高峰期依然流畅平稳。

### 2. 🛡️ 严格的质量监控与低丢包保障
灵动云始终关注端到端传输品质，杜绝超售与恶性拥堵。通过大带宽冗余储备与集群动态负载平衡，将跨国传输的丢包率与延迟抖动抑制在极低水平，保障实时视频通话与代码同步零卡顿。

### 3. 🎬 4K/8K 海外主流流媒体深度优化
专线节点天然适配主流海外音视频内容分发网络（CDN），支持高码率、高帧率视频流顺畅解码与快速首屏缓冲，配合客户端的分流规则，实现境内直连、境外加速互不干扰。

### 4. 🤖 生成式 AI（ChatGPT / Claude）纯净网络
针对 OpenAI ChatGPT、Anthropic Claude、Midjourney 等生成式 AI 平台的严格地区检测与长连接长轮询机制进行针对性出口纯净度优化，有效降低“Access Denied”与网络会话频繁中断风险。

### 5. 📱 全平台客户端无缝配置
全系采用成熟通用的 **Shadowsocks (SS) 协议**，支持通用订阅链接一键导入。完美兼容 Clash Verge、Clash Party、Mihomo、Shadowrocket（小火箭）、Surge、Sing-box 等主流客户端工具，单人多设备自由协同。

### 6. 🎧 官方直连客服与线路检测双保障
集成官方同款 **Crisp 7×24 实时在线技术客服**，支持网页直接唤起会话。同时提供官方【灵动云 线路检测】系统，自动测速并跳转至可用入口提交技术支持工单。

## 🛠️ 项目技术栈

- **核心框架**：[Astro 5](https://astro.build/)（零 JS 首屏开销、极速纯静态 SSG 输出）
- **UI 样式库**：[Tailwind CSS 4](https://tailwindcss.com/) + 原创科技星云暗色主题
- **类型安全**：[TypeScript](https://www.typescriptlang.org/)
- **Markdown 渲染引擎**：[marked v18](https://marked.js.org/)（定制化 AST 语法树解析，内建动态 TOC 目录大纲）
- **实时客服通讯**：[Crisp Chat SDK](https://crisp.chat/)（自定义科技云端动态悬浮启动器）
- **构建与托管**：Cloudflare Pages + GitHub Actions 持续集成自动化部署
